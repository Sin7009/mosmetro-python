# MosMetro Python

Асинхронный клиент для автоматической авторизации в сети Wi-Fi московского транспорта (MT_FREE) и других сетях с аналогичной системой авторизации.

Проект полностью переписан на Python 3.12+ с использованием современных библиотек (`httpx`, `typer`, `uv`).

## Возможности

*   🚀 **Асинхронность**: Быстрая работа благодаря `asyncio` и `httpx`.
*   🛠 **CLI Интерфейс**: Удобное управление через командную строку с помощью `typer` и `rich`.
*   📦 **Docker**: Готовый образ для запуска в контейнере.
*   📱 **Бинарная сборка**: Возможность собрать один исполняемый файл (exe/elf) для запуска без установки Python.
*   🔧 **Современный стек**: Использует `uv` для управления зависимостями.

## Требования

*   Python 3.12 или выше (для запуска из исходного кода).
*   Docker (опционально).

## Установка и запуск

### Использование uv (Рекомендуется)

Этот проект использует [uv](https://github.com/astral-sh/uv) для управления зависимостями.

1.  Установите `uv`, если он еще не установлен.
2.  Клонируйте репозиторий.
3.  Запустите:

```bash
# Авторизация
uv run python -m mosmetro login

# Проверка статуса
uv run python -m mosmetro status
```

### Использование pip

```bash
# Установка зависимостей
pip install .

# Запуск
mosmetro login
mosmetro status
```

### Docker

Вы можете запустить клиент через Docker, не устанавливая Python.

```bash
# Сборка образа
docker build -t mosmetro .

# Запуск (авторизация)
docker run --rm --network host mosmetro login

# Проверка статуса
docker run --rm --network host mosmetro status
```
*Примечание: `--network host` необходим, чтобы контейнер имел доступ к сети хоста для авторизации.*

## Команды

### `login`
Попытка авторизации в сети.
```bash
mosmetro login [--debug]
```
*   `--debug`: Включает подробный вывод логов.

### `status`
Проверка текущего статуса подключения.
```bash
mosmetro status [--debug]
```

## Сборка бинарного файла

Вы можете собрать standalone бинарный файл, который не требует установленного Python.

```bash
./build_binary.sh
```
Файл будет создан в директории `dist/mosmetro`.

## Разработка

Установка окружения для разработки:

```bash

```

